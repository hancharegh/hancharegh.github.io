Подключить общее пространство

Лента, настроение, рисунок и счётчик хранятся не у меня — а в вашем личном бесплатном Firebase-проекте. Займёт минут 5, один раз.

  1. Зайди на console.firebase.google.com → «Add project» → любое имя.
  2. Слева: Build → Firestore Database → Create database → режим test mode.
  3. ⚙️ → Project settings → «Your apps» → значок </> (Web app) → зарегистрируй.
  4. Появится блок firebaseConfig — скопируй целиком и вставь сюда:

Через 30 дней тестовый режим Firestore истечёт. В Rules поставь навсегда allow read, write: if true; и опубликуй. Правила открытые, поэтому просто не публикуй эту ссылку и конфиг никому, кроме своей половинки. Storage не нужен — фото хранятся прямо в Firestore.
